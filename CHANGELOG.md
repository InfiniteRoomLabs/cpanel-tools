# Changelog

## [0.1.0] - 2026-03-23

### Added

- Initial release of cpanel-tools
- `server-add` - Add servers to configuration
- `server-remove` - Remove servers from configuration
- `server-edit` - Edit server details (interactive or CLI)
- `server-list` - Display configured servers with status
- `server-verify` - Verify configurations and check accessibility
- `server-lookup` - Domain-to-server lookup with DNS and caching
- `server-account-query` - Query WHM account information
- `server-site-download` - Download site files via rsync
